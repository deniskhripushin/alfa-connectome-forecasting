# Данные

Получите данные у организаторов и разместите здесь:

- `train.parquet`: 10 607 row groups по 20 000 строк.
- `valid.parquet`: 1 873 row groups, включая `is_scored`.

Они исключены из Git и не включены в решение. Не заменяйте их случайной построчной
нарезкой: порядок внутри последовательности, границы и исходные fold-группы важны.

Полное обучение и official evaluation требуют эти файлы. Проверка готовой модели
на синтетических данных и сборка ZIP работают без них.
