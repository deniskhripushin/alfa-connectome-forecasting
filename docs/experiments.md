Основной урок: качество отдельной ветви не заменяет проверку её вклада в ансамбль.
Диагностические пять групп в отчётах не являются пятью независимо обученными CV-моделями.
Многократный выбор по одной валидации и несоответствие локального/серверного CPU
были существенными ограничениями исследования.
