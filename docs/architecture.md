# Обучение и потоковый инференс

1. `train.parquet` содержит 10 607 независимых последовательностей по 20 000 строк.
   Исходный fold 0: 8 485 train / 2 122 holdout. Его порядок сохранён в configs.
2. Mean/std рассчитывались по 256 последовательностям только из fold-train.
   Эта же нормализация зафиксирована для обеих финальных ветвей, включая full-data GRU.
   Нормализованный вход ограничивается диапазоном ±10.
3. На исходном fold выбирался GRU-рецепт. После выбора выполнялось **новое обучение
   с нуля** на всех 10 607 последовательностях, а не продолжение fold-чекпойнта:
   4 эпохи LR 0.0003 → EMA4 → новый optimizer/scaler/EMA/RNG → 1 эпоха LR 0.0001 → EMA5.
4. AE20 обучалась независимо на исходных 8 485 последовательностях. В каждом
   батче 8 последовательностей и по 512 выбранных без возвращения строк каждой.
   Для построения истории всё равно читается полная последовательность.
5. AE обучается совместно по трём потерям; отдельного предварительного
   unsupervised-pretraining Encoder в выбранном решении нет.

## Внутри AE

Чистый исторический вход `u` имеет 560 компонент. Encoder получает `u + noise`,
где Gaussian noise std 0.03 включён только при обучении. MLP получает
`concat(u, Encoder(u + noise))`: исходная часть skip-connection остаётся чистой.

- Encoder: Linear(560,128), ReLU, Linear(128,64), ReLU.
- Основная MLP: Linear(624,128), ReLU, Dropout(0.1), Linear(128,64), ReLU,
  Dropout(0.1), Linear(64,2), затем `2*tanh`.
- Decoder: Linear(64,128), ReLU, Linear(128,560).
- Auxiliary head: **на выходе Decoder**, Linear(560,2), затем `2*tanh`.
- Loss: WMSE(main,y) + 0.25 WMSE(aux,y) + 0.1 mean((reconstruction-u)^2).

Decoder и auxiliary head помогают обучать Encoder, но не исполняются в submission.
На инференсе также отключены input noise и dropout.

## Внутри GRU

Два последовательных GRU-слоя с hidden size 128; dropout 0.1 между слоями только
при обучении. На каждом шаге общий Linear(128,2) и `2*tanh` формируют два прогноза.
Hidden переносится между чанками одной последовательности и detach выполняется
на границе TBPTT 512. Loss не использует первые 99 warm-up строк.
EMA(0.999) обновляется только после реально состоявшегося AdamW шага, а не после
пропущенного AMP overflow. Между независимыми последовательностями hidden обнуляется.

## Инференс

`solution.py` принимает DataPoint. Каждая строка обновляет нормализованные входы,
кольцевой буфер на 20 шагов, EMA истории и оба hidden GRU. `need_prediction=False`
меняет только возвращаемое значение, а не обновление состояния.

Один ONNX Runtime session, 1 поток, CPUExecutionProvider, preallocated buffers и
IO binding. Python callback вызывает C-функцию для признаков и ONNX для ансамбля.
Исторические EMA внутри признаков и EMA весов при обучении — **разные механизмы**.

## Данные проверки

Внутренний holdout предназначен для fold-моделей. Official validation — отдельные
1 873 последовательности. Скрытый leaderboard test не доступен локально.
Предоставленный результат 646/5800 относится к финальному месту автора;
0.65490 — известная публичная оценка выбранного архива.
